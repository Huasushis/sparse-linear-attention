# 个人学习工作区

这里保存你亲手完成的作业、实验记录和报告草稿。教材与教师预跑结果只作为参考，不应复制成你的结论。

## 目录约定

- `progress.md`：唯一的个人进度表与下一步。
- `notes/`：章节检查题、手算、形状图和概念笔记。
- `papers/`：一篇论文一个笔记或复现卡。
- `labs/`：每个 Lab 的命令、环境、输出摘要、失败和解释。
- `runs/`：可提交 Git 的小型实验摘要；原始大日志放仓库根目录的 `artifacts/`。
- `report/draft.md`：逐阶段生长的学习草稿。
- `report/final.md`：算法、kernel、serving、论文尺度复现与 MQAR 效果实验的最终 Markdown 报告。

代码作业不放在这里，而在 `tutorial_code/exercises/` 中填写 `TODO`。

## 三条规则

1. 只在 `progress.md` 更新阶段完成状态；Lab 内清单只用于当次自检，网站不会保存复选框状态。
2. 结果必须附带来源：论文页码/图表，或实验的 commit、环境、命令和配置。
3. 模型权重、数据集、checkpoint、完整 profiler trace 和大日志不提交 Git。
