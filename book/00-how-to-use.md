# 使用这本书：用“通过条件”而不是进度焦虑推进

## 你的起点被认真对待

你已经知道原始 Transformer 的大致计算，也写过非常基础的 CUDA；这足以开始。你暂时不需要假装已经懂优化器、矩阵分块或 GPU 汇编。每章都会把“现在必须会”“只需认识”“以后再学”分开。

## 我们怎样分工

这套教程采用“先由教师走通，再由学生复做”的方式：

1. 我先阅读原论文与官方实现，实际运行 reference、测试和集群作业，保存环境、commit、
   失败原因与结果边界；
2. 我把走通过程整理成章节、最小代码、TODO、grader 和实验卡，而不是只给一串链接；
3. 你按章节亲手推导、填写 TODO、提交 Slurm job、记录结果，并用自己的话形成报告；
4. 你卡住时，我作为课程助教解释和诊断，可以给更小的例子或检查证据，但不替你填写
   应由你完成的作业与研究判断。

因此仓库里同时保留 `reference/` 与 `exercises/`：前者证明路线可走通，后者才是你的学习
现场。我的预运行结果是课程基线，不是你可以直接署名的实验结果。

## 每章的固定结构

1. **学习目标**：读完后可以做什么；
2. **直觉**：先回答“为什么需要它”；
3. **形式化**：用最少必要的符号、形状和伪代码；
4. **实现联系**：这件事如何落到 PyTorch / Triton / FLA；
5. **误区**：论文和代码最容易混淆什么；
6. **练习与通过条件**：你能自测，而不是凭感觉说“看懂了”。

## 三种阅读速度

| 模式 | 何时使用 | 要做什么 |
| --- | --- | --- |
| 通读 | 第一次进入一个主题 | 读直觉、图、例子和小结；不强迫自己记住所有符号 |
| 慢读 | A 级论文或核心章节 | 写形状、自己走一遍小数组、运行 reference |
| 证据读 | 准备复现或报告 | 读实现、实验设置、baseline、硬件、计时方法 |

## “我不懂”时的处理顺序

不要在同一页开十个搜索标签。先写下不懂的对象属于哪一类：

- **形状问题**：把张量写成 `[B,H,T,D]`；
- **公式问题**：先用 `T=3, D=2` 的小数组；
- **硬件问题**：问它在读写什么、哪些值需要留在片上；
- **论文问题**：问作者到底主张了什么，以及在什么设置下。

然后只补最靠前的依赖章节。第 1 章之前不需要读 Kimi 的 appendix；Lab 1 没做完也不需要启动 1M context benchmark。

## 研究笔记的最小格式

每次阅读或运行后写四句：

> **问题：** 旧方法在什么场景卡住？
>
> **改动：** 新方法改变了哪个计算、状态或访存步骤？
>
> **代价：** 它把成本转移到哪里，或可能损失什么？
>
> **证据：** 作者/我的实验在什么设置下观察到了什么？

这四句将直接长成报告内容。原始的完整模板仍在仓库的 `study/templates/` 中；本书的附录会告诉你何时使用它。

## 唯一必修主线

后续页面可能按主题回指章节，但不再提供另一套互相冲突的“推荐顺序”。第一次学习按下面
五个关卡推进；括号内是可以按需回看的参考，而不是新的并行任务。

1. **关卡 A，语言与最小训练：** 第 1、2、4 章，完成第 1 章形状题；重看 3Blue1Brown
   时把不懂的符号记下来。第 3 章需要外积/结合律时回看第 4 章对应小节。
2. **关卡 B，state 与 GPU 测量：** 第 3、5、6 章和 Lab 0；交出一份环境记录，并能区分
   算法复杂度、访存与实际计时。
3. **关卡 C，dense baseline：** 第 7--9 章和 Lab 1、4、5；先验证 dense reference，
   再理解 FlashAttention/Triton，分别测 prefill 与 decode。
4. **关卡 D，linear 主线：** 第 10--13 章和 Lab 2、3、6；完成三种 linear 表示、
   GDN/KDA state 等价实验，再进入 FLA。
5. **关卡 E，sparse 主线：** 第 14--16 章和 Lab 7；先做 structured sparse oracle，
   再从 NSA/MoBA/SpargeAttention 中只选一个现代方法升级复现。

每个关卡的可勾选任务和交付物在[研究路线与交付物](appendix/research-plan.md)；73 篇论文的
A0/A1/B/C 阅读层级在[论文阅读图](appendix/paper-map.md)。

!!! warning "不要把大模型训练当作第一项作业"
    这条路线先用小张量、算子级测试和已有实现建立判断力。完整预训练需要的数据、预算和工程组织远超当前研究问题；它不是衡量你是否理解 attention kernel 的标准。
