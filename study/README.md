## 术语的约定

- **算法（ALG）**：改变计算公式、状态表示或稀疏选择规则。
- **Kernel（KER）**：同一类计算如何映射到 GPU 的线程、存储和矩阵乘单元。
- **系统/服务（SYS）**：prefill、decode、KV cache、批处理和调度如何影响端到端吞吐和延迟。
- **复现**：在明确范围内验证一个可检验的主张；不等于完整重训论文中的最大模型。
